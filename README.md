# Bearma Staal Website

A standalone, responsive website for Bearma Staal, suitable for static hosting such as GitHub Pages.

## Pages

- `index.html` — Home
- `about/index.html` — About
- `services/index.html` — Services
- `gallery/index.html` — Gallery
- `contacts/index.html` — Contact

## Included

- Responsive industrial design
- Mobile navigation
- Scroll and hover effects
- Gallery category filters
- Quote enquiry form using the visitor’s email application
- Local image assets
- LocalBusiness structured data and SEO metadata

## GitHub Pages

1. Create a repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

No build step is required.

## Contact form

The quote form validates the visitor’s details and prepares an email in the visitor’s default mail application. It does not simulate a server-side submission.

## Images

The website contains local SVG image assets so the site does not depend on an external website for its primary visual assets. Replace these files with the company’s own high-resolution photography when available.
